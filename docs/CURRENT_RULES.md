# CURRENT_RULES

- 官网已有合格场景图优先复用。
- 缺 1 张只生成 1 张；缺 2 张才生成 2 张。
- 新生成必须提供原作品高清图。
- 必须按照真实物理尺寸展示。
- 普通布面、纸本、画芯、丙烯、油画等商品场景图默认必须有框。
- 只有木板画、特殊硬质载体、异形实体作品或不适合套常规框的作品才允许无框。
- 茗茗水果系列 P022-P026 属于特殊情况，可不使用常规矩形画框。
- 本规则高于旧的“原参考图无框就保持无框”判断。
- 场景允许重复。
- 不做后期贴片合成。
- 生成的是完整真实场景。
- 不修改作品内容。

## 强制 QA 门槛

- “找到两张场景图”不等于成功；任何商品只有在完成“原作品 vs 场景图”的逐图对照后，才允许标记为 `QA_PASS` / 最终成功。
- 必须检查作品有效画面是否完整：矩形作品四边不得被裁掉；圆形作品完整圆周不得缺失；不得被画框、卡纸、家具或其他物体遮挡有效画面。
- 必须检查内容一致性：不得丢失、替换、新增、镜像、重绘作品内部元素；颜色和光照可以受场景影响，但不能改变作品本身结构与主要色块关系。
- 必须检查装裱一致性：原有画框、卡纸、外框比例必须保留；无固定画框的作品不得凭空变成与原作冲突的固定装裱。
- 必须检查比例与透视：允许正常室内视角产生透视，但作品本体不得出现明显拉伸、压缩、弯曲或异常梯形变形。需要比较时，应先把场景中的作品区域做透视校正，再与原图对比。
- 必须检查真实尺寸感：结合已登记的真实尺寸判断挂墙后的相对尺度，不允许 30 cm 小画被展示成超大主墙画，也不允许 100 cm 作品被缩成装饰小摆件。
- 每个 `QA_PASS` 必须有可回看的 QA 证据图或对照记录；没有原图、没有场景原文件、无法确认匹配关系时，一律标记 `QA_NEEDS_MANUAL`，不得猜测通过。
- QA 结论必须使用明确失败原因，例如：`QA_FAIL_CROP`、`QA_FAIL_CONTENT`、`QA_FAIL_FRAME`、`QA_FAIL_SCALE`、`QA_FAIL_PERSPECTIVE`、`QA_NEEDS_MANUAL`。

## 交接与可移植性

- Manifest 中的 Windows 本地绝对路径只作为本机定位信息，不能作为跨会话唯一证据。
- 后续交接必须为每个商品至少提供一个跨会话可解析定位信息，例如 `artwork_lookup_key`（建议为“艺术家-作品名”）、公开 URL、仓库内 QA 证据相对路径或其他不包含密钥的可解析标识。
- 不得把 token、cookie、API key 或其他凭据提交到 GitHub。
